## Description (full Product Hunt "About" body)

**Write, plan, and collaborate with AI agents — from one calm workspace.**

Nexfiy started with a simple question: why does useful knowledge become harder
to use the moment it needs to leave the document where it was written?

Most work begins naturally. You write a note, collect research, draft a plan,
record a decision. Then the work grows — and the same information gets copied
into a project tracker, a CMS, a spreadsheet, an API payload, and an AI prompt.
Every copy creates distance from the source.

**Nexfiy keeps the source and the structure together.**

- **Pages first.** Block-based documents are still the fastest place to think:
  headings, lists, quotes, callouts, toggles, media, links, YouTube embeds, and
  GitHub cards.
- **Databases when it matters.** Turn repeated information into tables, boards,
  calendars, and timelines — with typed properties, relations, and saved views.
  A database row is *also* a full page.
- **A connected loop.** Capture → Structure → Connect → Act. Publish only the
  selected context through the Content API, or connect an approved AI client
  through a scoped MCP environment you fully control.
- **MCP-native.** Create per-client MCP environments with revocable URLs, let
  Codex, Claude, or other Streamable HTTP clients read and update content with
  only the tools you allow, and review every call in Activity history.
- **For teams.** Personal and organization workspaces, members, roles, shared
  billing, real-time sync backed by Convex, and full mobile responsiveness.

**Why AI changed the shape of the product:** an agent needs current facts,
stable identifiers, explicit relationships, and permission boundaries. A folder
full of disconnected prose isn't enough — and a database with no human
explanation isn't either. Nexfiy keeps the readable page and the structured
model together, and lets humans and agents work from the *same* source rather
than a separate AI-only copy.

**What it is not trying to be:** it's not a promise that every note must become
a database or that everything must be automated. A note can stay a note.
Structure and access are deliberate choices.

Nexfiy is in early access. Start with a personal workspace and add structure
only when the work asks for it.
