# Nexfiy — ElevenLabs launch video script

> A short voiceover (~60–75 seconds) for a Product Hunt launch / teaser video.
> Written to read naturally for text-to-speech: short sentences, clear pauses,
> no unusual punctuation, plain numbers.

## ElevenLabs settings (suggested)

| Setting            | Value                                                        |
| ------------------ | ------------------------------------------------------------ |
| Model              | Eleven Multilingual v2 / v3 (or Eleven Turbo for speed)       |
| Voice              | A warm, calm conversational voice (e.g. Adam, Rachel, or your custom voice) |
| Stability          | 0.45                                                          |
| Similarity         | 0.75                                                          |
| Style / Exaggeration | 0.15                                                        |
| Speaker Boost      | On                                                             |
| Speed              | 1.0 (slightly slower = more calm)                             |
| Format             | MP3 44.1kHz                                                   |

**Tip:** insert `[pause 0.5]` or use commas/periods to pace delivery. Keep the
whole read under 75 seconds.

---

## Script — Version A (narrative "why" focused)

```
[00:00] Why does useful knowledge become harder to use,
the moment it has to leave the document where it was written?

[00:08] You write a note. You collect research. You draft a plan.
Then the same information gets copied into a tracker,
a CMS, a spreadsheet, and an AI prompt.

[00:22] Every copy creates distance from the source.

[00:27] Nexfiy is a connected workspace.
Documents, databases, files, and links — all in one place.
Write freely. Add structure only when the work asks for it.

[00:42] And when your knowledge needs to power something else,
you expose just the parts you choose —
through a Content API, or through MCP.

[00:54] Codex, Claude, or any AI agent can now read and update
your workspace, using only the tools you allow.

[01:04] Your workspace becomes useful beyond the workspace.

[01:10] Nexfiy. Write once.
Stay connected.
```

## Script — Version B (feature-driven launch)

```
[00:00] Meet Nexfiy. The connected workspace for
documents, databases, and AI agents.

[00:08] Block-based pages for fast, calm writing.
[00:14] Databases that turn repeated information into
tables, boards, calendars, and timelines.

[00:26] One connected loop: capture, structure, connect, act.

[00:34] Need a website? Publish selected content through a
database-scoped Content API.

[00:44] Need AI? Create a scoped MCP environment.
Give Codex or Claude only the tools you allow,
and watch every call in your activity history.

[01:00] Real-time, private, and under your control.

[01:08] A note can stay a note.
When it becomes a process, connect it.

[01:15] Nexfiy. Your workspace, readable by
people, products, and AI.

[01:24] Try it free at nexfiy dot com.
```

## Shot list (for pairing with the voiceover)

1. 0:00 — Fade in on a blank, calm editor page; text being typed.
2. 0:08 — Rapid montage: note → tracker → CMS → spreadsheet → AI prompt.
3. 0:27 — Workspace grid: pages, files, links, database side-by-side.
4. 0:42 — A page "becomes" a database; a database view slides in.
5. 0:54 — MCP settings panel: create environment, copy scoped URL.
6. 1:04 — A Codex/Claude client reading the workspace in real time.
7. 1:15 — Logo and tagline on a clean background.
